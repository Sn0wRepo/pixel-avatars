Deterministic pixel identicons for wallet addresses: the same address always produces the same avatar. Three implementations give identical output:

| Part | Path | What it does |
| --- | --- | --- |
| Contract | `src/PixelAvatar.sol` | Fully on-chain SVG renderer (`svgOf`, `dataURIOf`, `tokenJSON`) |
| Crate + CLI (Rust) | `crate/` | `pixelid` library and CLI with SVG, PNG and batch output |
| Web app | `web/index.html` | Generator with previews, PNG/SVG export and a random gallery |

## Styles

- **Blockies:** port of `ethereum-blockies`, the pixel identicon MetaMask offers. At 8×8, seeded with the lowercase address, it matches MetaMask. The Rust port reproduces JavaScript's number semantics, so even Unicode seeds match.
- **PixelID v1:** an 8×8 mirrored grid with three HSL colours derived from `keccak256(address)`. It is rendered on-chain by `PixelAvatar.sol`.

## Quick start

```bash
cd crate
cargo run --release -- svg 0xYourWallet --style pixelid
cargo run --release -- png 0xYourWallet --scale 32 -o avatar.png
cargo run --release -- batch wallets.txt --format png -o avatars/

forge test
forge script script/Deploy.s.sol --rpc-url $RPC_URL --account deployer --broadcast
```

## Tests

`test/fixtures/avatars.json` was generated by the web app. Both suites check against it:

- **Foundry (7):** the on-chain `svgOf` matches the web output for 25 addresses. Also covers the base64 data URI, tokenJSON parsing, fuzzed mirror symmetry, and a gas snapshot (about 160k gas per render).
- **Rust (8):** PixelID and Blockies (8×8, 12×12, 5×5, text and Unicode seeds) match the web output byte for byte. Also checks PNG headers and HSL→RGB conversion.
